# Security Policy

## Supported versions

The latest published beta and stable releases are supported for security fixes.

## Reporting a vulnerability

Do not report security vulnerabilities in public GitHub issues.

Use GitHub private vulnerability reporting for this repository if it is enabled.
If private reporting is not available, contact the repository maintainers through GitHub and include:

- affected package version
- impact summary
- reproduction steps
- proof-of-concept or logs if available

The maintainers will review the report, confirm impact, and coordinate a fix and disclosure timeline.
